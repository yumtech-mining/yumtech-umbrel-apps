# Changelog

## 1.0.2

- CKPool verilerine uygun sade dashboard ve sabit başlık.
- Havuz diff toplamları ve madenci bilgilerinin gösterimi düzeltildi.

## 1.0.1

- Native CKPool sürümleriyle canlı veri uyumluluğu düzeltildi.
- Eski/eksik verilerin gösterimi ve dashboard güncellemesi iyileştirildi.

## 1.0.0

- Raspberry Pi 5 için tek komutlu native systemd kurulumu.
- Güncel CKPool Unix-socket API entegrasyonu.
- Gerçek share diff/hash, kalıcı best share ve blok geçmişi.
- Bitcoin Core ve Bitcoin Knots RPC telemetrisi.
- Stratum V1/V2 bağlantı ve public authority key görünümü.
